About

Qara's cherries. Germany's habits.

Karaz — كرز — is Arabic for cherry, the fruit our city, Qara, has grown for generations. That's where the name comes from.

Karaz Dev is a small web and mobile studio based in Qara, Syria. Our engineering habits come from somewhere else, though — time spent working inside Germany's tech industry, where code review, testing, and performance budgets aren't optional extras, they're just how software gets built.

We brought that back home. Every project we ship gets held to the same bar, with one addition the industry we learned from doesn't usually have to think about: most of the people using what we build are on a connection that drops, not a fibre line. So we design for that from the start, not as a fix afterward.
